# 🔥 FLAMES Game

A simple Python implementation of the classic FLAMES relationship game.

## About

FLAMES stands for:

* **F** – Friends
* **L** – Love
* **A** – Affection
* **M** – Marriage
* **E** – Enemies
* **S** – Siblings

The program takes two names as input, removes common letters, counts the remaining letters, and uses the FLAMES elimination process to determine the relationship.

## Features

* Takes two names as input
* Removes common characters
* Counts remaining letters
* Implements the FLAMES elimination algorithm
* Displays the final relationship result

## Requirements

* Python 3
